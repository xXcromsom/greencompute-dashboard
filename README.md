# GreenCompute dashboard · WAS Group 2

Interactive dashboard for the group report *GreenCompute: AI-driven energy and computing optimization for sustainable data centres* (NAT Consulting and Project Management, BBA Semester 5).

**GreenCore Data Services is a hypothetical client.** Every figure carries a provenance tag:

| Tag | Meaning |
| --- | --- |
| synthetic | Generated by the app with a fixed seed. Not real facility data |
| measured | Measured live on the server running the app (code benchmark only) |
| projected | Scenario output from the report's stated assumptions |
| report | Planning figure copied from the report |

No real energy or cost savings are claimed. Code runtime is never converted to kWh or rupees.

## Pages
1. Overview: headline figures, forecast chart, alerts, proposal summary, team
2. Energy workstream: synthetic telemetry, ML vs historical-average and persistence baselines (chronological split), anomaly detection with recall/precision, alert log, trends, model card
3. Code optimization: live benchmark of a baseline vs optimized Python workload, CPU time, tracemalloc memory, output-equality check
4. Financials: ₹8,20,000 budget, milestone billing, scenario calculator (payback 117.1 / 25.2 / 14.1 months at 2 / 5 / 8%)
5. Plan and governance: 12-week roadmap, WBS, RACI
6. Risks: likelihood × impact grid and register
7. KPIs and conclusion: acceptance criteria checked live, hypotheses, KPIs, alternatives
